### 独自要素・講師相談メモ

- 独自要素: LINE Messaging API を使ったメッセージ送信連携。LINEボット側で事前にチャネルアクセストークンとユーザーIDを取得し、テンプレート送信を行う。
- 料金試算（N 件のとき月いくら）: LINE Messaging API のメッセージ送信単価は公式価格を要確認。最初は「送信件数 1000 件/月」で無料枠や最小課金ラインを確認する。\n- 講師に相談すること: LINE公式アカウントのメッセージ送信上限・料金体系、LINEミニアプリとボットのどちらがPoCに適しているか、またVercel無料枠でAPI運用が可能か。

### 3 段プロンプト下書き（題材: LINEメッセージ送信APIのNext.js API Route）

> 【前提】
> Next.js 14/15 を使ったプロジェクトで、`pages/api/send-line-message.js` または `app/api/send-line-message/route.js` に実装する。環境変数 `LINE_CHANNEL_ACCESS_TOKEN` と `LINE_TO_USER_ID` が設定されている。
>
> 【目的】
> LINE Messaging API の `push` エンドポイントに対して固定メッセージを送信し、送信結果を JSON で返す最小APIを作る。
>
> 【制約】
> ・ フロントUIは不要。APIを直接呼び出すだけでよい
> ・ 送信内容は固定テキストとし、リクエストボディは利用しない
> ・ エラーはHTTPステータスとJSONレスポンスで返す
> ・ 依存ライブラリはNode標準の `fetch` または `node-fetch` のみとする

### ⚠ 弱さ（→ Stage 19 検証へ）

- LINE Messaging API の実際の送信成功やユーザー受信体験、LINEプラットフォーム上での承認条件はまだ未検証。

> 例: 「N 件超で API コストが粗利を逆転するリスク」
