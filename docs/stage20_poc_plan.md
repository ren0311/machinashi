## ✅ 最終アウトプット — PoC 計画書

### ■ 安心待ち合わせテンプレ PoC 計画書

**▸ 仮説**

- 都心部で週1回以上友人とカフェ待ち合わせをする20〜30代女性は、LINEでワンタップ送信できる「待ち合わせ安心テンプレート」を使うことで、待ち合わせ中の不安感が減り、月額500円のサービスなら支払いたいと感じるようになる。

**▸ 検証方法**

- 実装で確かめる:
  - 最小LINE送信PoCを作成し、LINE公式アカウント経由でテンプレートを送信できる体験を構築する。対象ユーザーに実際の待ち合わせで使ってもらい、送信成功率・再利用率・待ち合わせ不安軽減スコア・課金意向を測定する。
- 実装せず確かめる:
  - LPと早期アクセス登録フォームを用意し、事前に価値説明を提示。対象ユーザーに人力代行でテンプレート送信体験を提供して、反応や理解度、価格受容性をインタビューで確認する。

**▸ 成功条件（後から動かせない数値で）**

- B検証で、対象ユーザーから20件以上の早期アクセス登録を獲得し、ヒアリング参加者のうち35%以上が500円の月額支払いに前向きと回答すること。
- A検証で、10人以上の実利用中に送信されたテンプレートのうち60%以上が「不安が軽くなった」と自己申告し、3人以上が継続課金意向を示すこと。

**▸ 失敗・撤退条件**

- B検証で20件未満の早期アクセス登録、またはヒアリング参加者の中で500円の月額課金意向が30%未満の場合は、A実装に進む前に撤退を検討する。
- A検証で実利用10件中6件未満が不安軽減を感じる、または継続課金意向が2人以下の場合は、設計変更または撤退とする。

**▸ スケジュール（4 週間・週次マイルストーン）**

| 週 | やること |
| --- | --- |
| 週 1 | PoCの最小範囲を確定し、LP・早期アクセスフォーム・インタビューガイドを準備。対象ユーザーの募集を開始し、LINE公式アカウントの申請要件を確認。 |
| 週 2 | B検証としてLP公開と人力体験を開始。早期アクセス登録とインタビューを進めると同時に、LINE送信PoCの基盤（API連携・認証・テンプレート管理）を構築。 |
| 週 3 | A検証として実ユーザーにPoCを提供し、実際の待ち合わせでテンプレート送信を実行。送信率・再利用率・不安軽減スコア・課金意向を収集。 |
| 週 4 | 収集した定量・定性データを集計・分析し、成功/失敗条件と次の判断を確定。講師レビュー用の結果レポートと次工程提案を作成。 |

**▸ 必要リソース（自分の時間・他者の協力・実費）**

- 自分の時間: 4週間で合計約50〜60時間。LP作成・インタビュー設計・PoC開発・データ集計を含む。
- 他者の協力: 10〜20人の待ち合わせ実体験者（友人/知人/募集参加者）、1人程度のメンターまたは技術相談相手。
- 実費: LINE公式アカウント登録・メッセージ費用の検証用コスト（概算5,000円程度）、参加者への謝礼/インセンティブ（3,000〜5,000円程度）、LP公開費用は無料枠利用可。
